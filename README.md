
# Home Loan Eligibility Prediction

##  Project Overview
This project performs exploratory data analysis (EDA) and builds machine learning models to predict home loan eligibility based on applicant financial and demographic details.

##  Objectives
- Analyze customer income, credit history, and loan features
- Identify key factors influencing loan approval
- Develop a predictive classification model

##  Models Implemented
- Logistic Regression
- Random Forest
- Gradient Boosting

##  Model Evaluation
Performance evaluated using Accuracy, Confusion Matrix, Precision, Recall, and Cross Validation.

## Technologies Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

## Business Impact
Helps financial institutions reduce credit risk and improve data-driven loan approval decisions.
